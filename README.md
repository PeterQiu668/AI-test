## 联网扫描（2026-10-23 实测）

- 数据源：博查全网搜索（推荐，单 Key）、DeepSeek Search API（已实测可用）、豆包、元宝；归纳模型默认 DeepSeek。
- 用户填写官网时直接读取官网标题/描述/标题，作为第一方证据并以它确定主体。
- GEO 测试由模型生成“买家不知道你时会问的选购问题”，并校验问题里不含公司名/品牌/证券代码。
- 名称有多家同名企业时提示补充官网，不生成画像。
- 后台每个搜索源有「测试连接」，失败时显示平台原始原因（欠费/Key 无效等）；客户端只显示“暂不可用”。
- `engine.mjs` 热加载：改扫描逻辑无需重启（重启会丢失解锁状态，需管理员重新解锁）。

## v4.1 上线化（2026-10-23）

- 可视化：首页/扫描/计算页的环形“企业画像”动态图（四个节点随扫描阶段点亮）、成熟度环形仪表、六维雷达图、AI 可见度“客户提问 → AI 检索结果”对话视图、场景与维度图标、工时区间条、案例行业色标、路线图图标；报告各节滚动渐入（带超时兜底）。
- 答题：选项改为 1–4 格强度条，选中有粒子反馈；章节以维度图标标签呈现。
- 文案：移除所有开发/演示字眼；示例报告改为匿名“某跨境家居电商”，仅标“报告示例”。
- 线索：`POST /api/lead` 写入 `%LOCALAPPDATA%\KunjieAIDiagnosis\leads.jsonl`（站点目录之外）；后台顶部新增“预约线索”列表（需解锁）。

## 诚实边界

- 未配置 Key 时，扫描各步骤显示“未接入”，不伪造结果；样例报告明确标注演示数据。
- AI 搜索检测使用官方搜索 API，代表接口召回，不等于消费者 App 内排名。
- 线索表单仅存本机，未接服务端。权重与阈值为 v0.4 假设，需真实样本校准。

后端（server/engine/vault/admin）沿用 v3，仅新增 `/api/scan-stream`；v3 目录未改动。
